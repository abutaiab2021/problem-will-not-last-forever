Github a code push korar niyom

Github a code push korar somoy kiso rules amader mene cholte hobe. Prothome amader jei jinista mone rakhte hobe ami github jei name repository khulbo thik sei namei amar local computer a folder name khulte hobe.example hole my-first-github. then oi folder a first html file ta hobe must be index.html jodi index diye first form ta khula na hoy ta hole onek somoy oi website kothao deploy kora hoy tokhon thik moto website ta show korbe na. tarpor aro joto file ase create kore. then amra jokhon github code push korte jabo. amara vs code theke ctrl + j ak sathe click korte hobe. then repository khular somoy jei command golo dise oi command golo ak ak kore chalate hobe. kinto amader akta kotha mone rakhte hobe jodi kono akta pc theke er age kokhono github a code push kora na hoye thake ta hole first a apni ki original person kina tar jonno apnar email and jei user name ta github a ase oi name ta diye 2ta comman apnar command promt a dekhabe. apni oi 2ta command copy kore apni chaliye diyen. ai 2 ta code apnake ak bari dite hobe. tarpor arakta jinis apanake khewal korte hobe. je apar pc thek jei browser a apni github code push korte chassen. oitar jonno tara email varification code pathiye tara apnake prothom barer moto verify kore nibe. then baki jei command golo akta akta kore chaliye diben taile asa kori code push hoye jabe.
